# Travel Pins — 需求規格（Requirements）

本文件列出在其他專案/技術棧重建 Travel Pins 功能時，需要滿足的「需求」（不包含實作細節）。

## 核心目標
- 在地球地圖上展示「旅遊釘點（Pin）」資訊，提供快速檢視、建立、編輯、刪除與分享連結能力。
- 在桌機與行動裝置上具備一致、順暢的互動體驗。
- style 參考 'src/Pages/TravelPins'，但需重新建立一份到 'src/Pages/TravelPinsNew'，並非直接複製。
- 目的在於根據現有需求重新設計與實作，並非逐字複製現有程式碼，藉此移除不必要的複雜度與技術債。
- 實作過程避免將所有邏輯塞在單一檔案中，應拆分成多個元件與模組。
- 針對此需求表，建立細項的任務清單（To Do List）以利追蹤。

## 功能需求

### 1) 地圖與視覺
- 必須提供可旋轉/縮放/平移的地球地圖視圖。
- 行動裝置上，地球視覺位置需上移，使在常見 3/4 視窗高時不顯得過低。

### 2) 釘點（Pins）
- 建立釘點後，必須立即出現在地圖上（無需重新整理）。
- 釘點包含：id、標題、備註（支援 Markdown 呈現）、造訪日期、座標（經緯度）、單張照片 URL（選填）。
- 釘點在地球「背面」不應被看見；使用者需要旋轉到其所在面才會顯示。
- PIN 需有 Hover 效果，效果應與目前的 style 一致
- 當兩個釘點在螢幕上距離過近時，應顯示不同顏色以便區分識別

### 3) 顯示視窗（Display Popup／釘點資訊）
- 點擊釘點可開啟顯示視窗，顯示標題、造訪日期、備註（Markdown 轉為 HTML）、照片縮圖（若有）。
- 顯示視窗內需要提供：
  - 「複製連結」按鈕：複製可深連結至該釘點的 URL。(無需登入)
  - 「編輯」按鈕：開啟編輯視窗。(需登入才顯示)
  - 「刪除」按鈕：開啟刪除確認視窗。(需登入才顯示)
  - 照片點擊：開啟全螢幕照片檢視（若有照片）。
- 開啟任何顯示視窗時，顯示背景遮罩以聚焦內容。
- style 可參考目前的 style

### 4) 建立/編輯（Form Modal）
- 提供建立與編輯釘點的表單：標題（必填）、備註（Markdown）、造訪日期(若無提供，則自動帶入當天日期)、照片 URL、座標顯示。
- 表單送出成功後，顯示視窗與列表/地圖應反映最新資料。
- 未登入時觸發建立/編輯行為，必須引導登入（以登入視窗或提示）。
- 開啟視窗時，顯示背景遮罩以聚焦內容。
- style 可參考目前的 style
- 取消編輯時，若有未儲存變更，必須顯示確認對話框以避免誤觸關閉導致資料遺失。
- 取消編輯時，若無未儲存變更，直接關閉視窗回到 display popup。

### 5) 刪除確認（Delete Modal）
- 刪除前必須顯示確認對話框，包含釘點摘要資訊。
- 刪除確認視窗開啟期間：
- 開啟視窗時，顯示背景遮罩以聚焦內容。
- 若點擊取消，回到 Display Popup
- 若點擊刪除，釘點從地圖與資料來源移除。

### 6) 照片檢視（Photo Modal）
- 以全螢幕方式檢視釘點照片，支持關閉返回。
- 開啟視窗時，顯示背景遮罩以聚焦內容。

### 7) 深連結（Deep-link）
- 連結格式：`/travel-pins?pin=<id>`（或等價 URL 規格）。
- 打開此連結時：
  - 地圖需自動移動到該釘點座標範圍（可視範圍內，zoom in 程度拉到國家範圍即可）。
  - 對應釘點的「顯示視窗」需自動打開。

### 8) 複製連結（Copy Link）
- 顯示視窗內的複製按鈕必須複製可深連結到該釘點的 URL。
- 成功複製後應有短暫的視覺回饋（例如按鈕狀態切換或提示）。

### 9) 互動與遮罩
- 當以下任一類型對話框開啟時，背景地圖與頁面不可操作；關閉後恢復。
  - display popup
  - form modal（建立/編輯）
  - delete modal
  - photo modal
  - 其他未來可能新增的阻塞型對話框

### 10) 權限與登入
- 未登入使用者：
  - 點擊需要權限的操作（新建、編輯、刪除）時，必須先要求登入或提示無權限。
- 已登入使用者：可完整使用上述功能。
- 未登入時，釘點仍可顯示與檢視，但不顯示編輯/刪除按鈕。

### 11) 國際化（i18n）
- 所有文案需支援多語系（至少現有語言），日期/數字格式需符合在地化設定。
- style 可參考目前的 style
- 當前專案已使用 React intl，請沿用相同機制。
- locale message 已有定義，可沿用現有 key。

### 12) 搜尋功能
- 於頁面頂部提供搜尋欄位，允許搜尋 地名，並顯示建議清單。
- 於頁面頂部提供搜尋欄位，允許搜尋 座標，並顯示建議清單。
- 點擊建議清單項目，地圖需自動移動到該位置並縮放至適當範圍。
- 按下 Ctrl/Cmd + F，自動聚焦搜尋欄位。
- 搜尋欄位聚焦時，按下 ESC 鍵取消聚焦並關閉建議清單。

### 13) ESC 行為
- 根據不同的 modal open 狀態，按下 ESC 鍵的行為如下：
  - 開啟刪除確認視窗時，按 ESC 關閉刪除視窗，回到顯示視窗。
  - 開啟照片檢視視窗時，按 ESC 關閉照片視窗，回到顯示視窗。
  - 開啟顯示視窗時，按 ESC 關閉顯示視窗，回到地圖（無任何視窗開啟）。
  - 編輯視窗開啟且有未儲存變更時，按 ESC 顯示確認對話框以避免誤觸關閉導致資料遺失。
  - 編輯視窗開啟且無未儲存變更時，按 ESC 關閉編輯視窗，回到顯示視窗。

### 14) 手勢切換按鈕
- 當單指頭滑動時，分為兩種可能，旋轉地球 or 捲動視窗內容。
- 提供一個切換按鈕，讓使用者可以在「旋轉地球」與「捲動視窗內容」兩種手勢模式間切換。
- 切換按鈕應固定在視窗內的明顯位置，並有清楚的圖示與提示文字。
- 切換按鈕的狀態（旋轉 or 捲動）應有明顯的視覺回饋。
- 切換按鈕的狀態應在頁面重新整理後保持一致（可使用 localStorage 或其他方式儲存）。
- 參考目前的 style

### 15) 取得使用者位置
- 提供一個按鈕，點擊後嘗試取得使用者的地理位置，並將地圖移動到該位置。
- 若使用者拒絕授權或無法取得位置，應顯示適當的錯誤訊息。
- 參考目前的 style

## 非功能性需求（NFR）
- 性能：
  - 大量釘點時仍須維持流暢互動（新增/移動/縮放/開關視窗）。
- 行動裝置體驗：
  - 可順暢捲動視窗內容、避免手勢與地圖衝突；視窗內滾動不應影響地圖。
- 可近用性（a11y）：
  - 模態視窗具備 `role="dialog"` 與可用鍵盤操作；提供明確的關閉方式。
- 穩定性：
  - 深連結自動開啟視窗行為在常見瀏覽器與裝置上需穩定可靠。
- 安全性：
  - 不得在前端儲存敏感資訊；複製的連結不得外洩非公開資料。

## 最小資料模型（建議）
- Pin：
  - `id`（字串/數字）、`title`（字串，必填）、`note`（字串，Markdown，選填）、`visited_at`（ISO 字串，選填）、`coordinates`（[lng, lat]）、`photo_url`（字串，選填）、`photos`（陣列，選填）。

## 驗收準則（摘錄）
- 新增釘點後，無刷新立即顯示於地圖。
- 不在視野面（地球背面）的釘點不顯示；旋轉到其面後顯示。
- 點擊釘點可開啟顯示視窗；視窗內可複製連結、進入編輯、進入刪除確認、開啟照片檢視。
- 開啟阻塞型對話框時，背景不可互動；關閉後恢復。
- 造訪 `.../travel-pins-new?pin=<id>` 時，地圖會帶到該釘點並自動打開顯示視窗。
